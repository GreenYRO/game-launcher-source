## Română

**Launcher-ul îți spune ce e nou.** De la această versiune, la prima pornire după o actualizare, launcher-ul îți arată o dată, într-o fereastră, ce aduce versiunea: **What's new in 1.2.10** (chiar aceasta). O închizi cu **Close** și nu mai apare. Oricând o găsești în Settings → About → **What's new**; iar când a apărut o versiune și mai nouă, rândul Updates din același loc îți arată ce aduce ea, înainte s-o instalezi (**See what's new in ...**).

**Coperțile care lipsesc, toate deodată.** Dacă ai o cheie SteamGridDB, în Settings → Artwork and the internet rândul nou **Missing covers** spune câte jocuri n-au copertă, iar **Fill missing covers...** le caută pe toate deodată, după o copie de siguranță. Pune doar coperta, nu schimbă niciodată una aleasă de tine și sare peste numele care nu seamănă destul; pe acelea le găsești ca până acum, cu Find online din meniul jocului. Dacă nu-ți plac coperțile găsite, Settings → Your library data → Restore..., cu copia numită la sfârșit, pune biblioteca înapoi cum era.

**O reparație.** Când SteamGridDB cere să întrebi mai rar, launcher-ul nu mai ține minte jocul ca „nu există acolo”, iar butonul Test spune ce s-a întâmplat, nu că cheia ar fi greșită.

Biblioteca nu se schimbă la această versiune. Închide launcher-ul (dacă stă lângă ceas: clic dreapta → Quit), apoi rulează noul `GameLauncher-Setup.exe` peste cel vechi; totul se păstrează.

Codul sursă al launcher-ului e public, cu documentele lucrării de licență: https://github.com/GreenYRO/game-launcher-source

## English

**The launcher tells you what's new.** From this version on, on the first start after an update, the launcher shows you once, in a window, what the version brings: **What's new in 1.2.10** (this very one). Close it with **Close** and it doesn't come back. You can find it any time in Settings → About → **What's new**; and when an even newer version is out, the Updates row in the same place shows what it brings, before you install it (**See what's new in ...**).

**Missing covers, all at once.** If you have a SteamGridDB key, the new **Missing covers** row in Settings → Artwork and the internet says how many games have no cover, and **Fill missing covers...** looks them all up at once, after a backup copy. It only sets the cover, never changes one you chose yourself, and skips names that aren't close enough; for those, use Find online from the game's menu, as before. If you don't like the covers it found, Settings → Your library data → Restore..., with the backup named at the end, puts your library back as it was.

**A fix.** When SteamGridDB asks to be asked less often, the launcher no longer remembers the game as "not there", and the Test button says what happened instead of calling your key wrong.

Your library does not change in this version. Close the launcher (if it sits by the clock: right-click → Quit), then run the new `GameLauncher-Setup.exe` over the old one; everything is kept.

The launcher's source code is public, with the thesis documents: https://github.com/GreenYRO/game-launcher-source
